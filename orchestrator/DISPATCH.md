> 총괄자가 대신 발령하는 예외다.** 계약 변경 권한은 여전히 jin 에게 있고, 아래 어떤 항목도

## 0. 지금 상황 한 줄

```
A ──(1) 매니페스트 커밋 ─────────────► C 의 D-13 착수 가능
```

## 1. A — data-platform · **최우선. 다른 셋이 너를 기다린다**

이 순서를 바꾸지 마라. 순서 자체가 이번 지시의 내용이다.

| # | 작업 | 근거 | 끝났다고 말할 조건 |
|---|---|---|---|
| A-1 | `.gitignore` 분리 + `output/manifest/regions-{level}-{vintage}.json` 커밋 | D-11 | `git ls-files data-platform/output/manifest` 가 비어 있지 않고, `git ls-files '*.pmtiles'` 가 **비어 있음** |
| A-2 | `region_id` 를 properties 에 문자열로 유지 + 매니페스트에서 `id_map_path` 제거 | **D-20 / ADR-005** `data-platform/.venv/Scripts/python.exe verification/fixtures/vf_56_tile_probe.py` 가 `'region_id' in properties -> True` |
| A-3 | **빌드 자체 검증**: 광고한 `feature_id_property` 가 산출 타일에 없으면 빌드 실패 | ADR-005 | 일부러 속성을 빼고 빌드 → **실패**하는 것을 확인. 통과하면 검사가 가짜다 |
| A-4 | `sigungu` 픽스처 타일 + `manifest-fixture.json` (5MB 이하, `boundary_vintage: "fixture"`) | D-12 | A-3 검사를 통과한 파이프라인으로 구운 것일 것 |
| A-5 | 레벨 산출 순서 `sigungu` → `adm_dong` → `sido` | D-13 | — |

**A-3 을 A-4 보다 먼저 하는 이유**: 지금 파이프라인으로 픽스처를 구우면 `region_id` 없는 픽스처가
나온다. D 는 뚫린 줄 알고 붙였다가 또 회색 지도를 본다. **개정 2 의 "픽스처가 최우선" 은 이 지시로 취소한다.**

**멈출 것**: `.pmtiles` 를 git 에 넣지 마라 (D-11). 타일 서빙 API 를 만들지 마라 (D-05).

## 5. 공통 — 회신 형식

"다 했습니다"는 보고가 아니다. 각자 커밋 후 자기 `RECONCILIATION.md` 에 이 세 줄을 남겨라.

```
- 끝낸 항목: A-1, A-2 (지시 번호로)
- 통과 확인: <위 표의 '끝났다고 말할 조건' 명령과 그 출력>
- 못 한 것과 이유: <없으면 '없음'. 추측으로 채우지 말 것>
```

**막히면 자기 폴더 문서에 질문으로 남기고 계약 기준으로 진행한다** (D-10).
다른 에이전트의 코드를 계약으로 오인해 자기 작업을 되돌리지 마라 — A 가 이미 한 번 그럴 뻔했다.
